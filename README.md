# BLACKMEVALLY Portfolio

Software systems, digital solutions, and practical automation.

## Stack

- PHP 8+
- HTML5 / CSS3 / JavaScript
- Apache / XAMPP
- No database required for the portfolio itself

## Local XAMPP

Clone or copy this repository to:

```text
C:\xampp\htdocs\portfolio
```

Start Apache in XAMPP, then open:

```text
http://localhost/portfolio/
```

## Portfolio structure

The portfolio is data-driven from `config/projects.php`, with reusable project pages handled by `project.php`.

Project commercial status is intentionally separated from repository visibility. A project may be public on GitHub while still being offered as a commercial deployment, customization, integration, or support service.

- Healthcare

- Infrastructure

## Notes

Repository links and current implementation status should be treated as the source of truth. Concept or in-development products are clearly marked rather than presented as production software.
